# Sound credits

Every built-in sound is synthesized by a script in this repo. No recordings, samples, or third-party audio are included, so there is no external source URL, nothing to attribute, and no outside license to follow. The files are original to Duet and dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

All files are mono 16-bit 44.1 kHz WAV, normalized to -20 dBFS RMS, and loop without a click. The noise files crossfade their tail into their head. The ambient files are built to be exactly periodic, so their end already flows into their start. Both scripts use fixed seeds, so rerunning them reproduces the same files byte for byte. If a sound is ever replaced with a recording, add its source URL, author, and license here.
